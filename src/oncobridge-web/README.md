# OncoBridge web

The Angular workbench. Start with the [root README](../../README.md) — it explains what OncoBridge
is, and `docker compose up --build` from the repository root runs this application together with the
API and PostgreSQL.

This file only covers working on the frontend itself.

## Commands

| Command                  | What it does                                                                               |
| ------------------------ | ------------------------------------------------------------------------------------------ |
| `npm start`              | Dev server on <http://localhost:4200>, proxying `/api` to <http://127.0.0.1:5080>          |
| `npm run build`          | Production build into `dist/`                                                              |
| `npm run test:ci`        | Component tests once, under Vitest                                                         |
| `npm test`               | The same tests in watch mode                                                               |
| `npm run e2e`            | Starts PostgreSQL, the API and Angular on free ports, then runs the one Playwright journey |
| `npm run api:check`      | Fails if the committed API client has drifted from the OpenAPI snapshot                    |
| `npm run api:generate`   | Regenerates the API client from the snapshot                                               |
| `npm run screenshots`    | Rewrites `docs/screenshots` from a running Compose stack                                   |
| `npx prettier --check .` | Formatting gate                                                                            |

`npm start` expects an API already running on port 5080; the root README's "Running without Docker"
section shows how to start one.

## The generated API client

`src/app/api` is generated by `ng-openapi-gen` from
`tests/OncoBridge.Api.Tests/Snapshots/openapi-v1.json`, which is the committed snapshot of the API's
OpenAPI document. **Never hand-edit those files** — `npm run api:check` compares them byte for byte
against a fresh generation and fails on any difference. They are excluded from Prettier for the same
reason.

To change the client, change the API contract, refresh the snapshot, then run `npm run api:generate`.

## Conventions

Standalone components with signal inputs and `ChangeDetectionStrategy.OnPush`, `ob-` selector
prefix, styles co-located in the component. The codebase carries no explanatory comments by
design — rationale lives in [`docs/adr`](../../docs/adr/README.md).
